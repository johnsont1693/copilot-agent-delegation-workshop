## Session objective

By the end of this session, participants will be able to:

1. Choose the right customization mechanism for the job: `copilot-instructions.md` for essentials, path-specific instructions for layer conventions, `AGENTS.md` for agent norms, skills for repeatable workflows, and prompt files for task templates.
2. Give an agent a well-defined goal, context, constraints, and definition of done — and get a plan they can approve before any code is written.
3. Create a reusable skill that encodes a team pattern so every developer gets consistent, governed agent behavior.
